Wanderer Payment — ปรับกรอบธนาคาร + โน้ตในกรอบแจ้งเตือน

อัปเดตเฉพาะ 2 ไฟล์: index.html และ style.css ใน GitHub Repository เดิม (วางระดับเดียวกับไฟล์เดิม)
1. แตก ZIP
2. อัปโหลด index.html และ style.css เพื่อแทนชื่อเดิม แล้ว Commit changes
3. รอให้ Cloudflare Pages Deploy สำเร็จ แล้วกด Ctrl+F5 เพื่อโหลดใหม่

แก้ไข:
- กรอบธนาคารแบบไล่สีม่วงฟ้าเหมือนกรอบพร้อมเพย์ มีชื่อธนาคาร ชื่อบัญชี เลขบัญชี และปุ่มคัดลอกเลขบัญชีในกรอบเดียวกัน
- ไม่มีปุ่มคัดลอกชื่อบัญชี
- โน้ตสลิปพร้อมปุ่มคัดลอกอยู่ภายในกรอบแจ้งเตือนด้านบน ส่วนข้อความเตือนกับโน้ตยังเป็นคนละข้อความ
- ใช้ id เดิมทุกตัว (bank, bankName, bankNumber, copyNumber, warningText, slipNote, copyNote) จึงไม่ต้องแก้ main.js หรือ D1

ก่อนอัปเดตตรวจว่า main.js เป็นชุดล่าสุดที่มี copyNote และ warningText; ถ้าไม่ใช่ให้ใช้ JS จาก ZIP อัปเดตครั้งก่อน
