# Wanderer Payment (แยกจากเว็บร้านหลัก)

ชุดนี้ใช้ **GitHub เก็บโค้ด → Cloudflare Pages แสดงเว็บ → Cloudflare Worker + D1 เก็บข้อมูลส่วนกลาง**

- `/web/index.html` หน้าลูกค้า: เลขบัญชี, คัดลอก, QR, โลโก้, ข้อความเตือน และเมนูลอยที่มีปุ่มแอดมิน
- `/web/admin.html` หน้าแอดมินหลังล็อกอิน: แก้ชื่อร้าน, เลขบัญชี, QR, สี, รูปพื้นหลัง, รูปตกแต่งลอย, ข้อความลอย, และลิงก์
- `/worker/src.js` API + ระบบตรวจรหัสผ่านและโทเค็น 4 ชั่วโมง + จำกัดจำนวนล็อกอินผิด
- `/worker/migrations/0001_init.sql` ตาราง D1 ใหม่ ไม่ใช้ตารางของเว็บร้านหลัก

## 1) สร้างฐานข้อมูลใหม่

ติดตั้ง Node.js และ Wrangler แล้วรันในโฟลเดอร์ `worker`:

```powershell
npx wrangler login
npx wrangler d1 create wanderer-payment-db
```

นำ `database_id` ที่ได้ไปแทนใน `worker/wrangler.toml` (อย่าใช้ ID จากเว็บร้านหลัก)

```powershell
npx wrangler d1 migrations apply wanderer-payment-db --remote
```

## 2) ตั้งค่า Worker และรหัสลับ

ใน `worker/wrangler.toml` เปลี่ยน `ALLOWED_ORIGIN` ให้ตรงกับที่อยู่ Pages ใหม่ เช่น `https://wanderer-pay.pages.dev`

```powershell
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put SESSION_SECRET
npx wrangler deploy
```

- `ADMIN_PASSWORD`: ตั้งรหัสแอดมินยาวและเดายาก ไม่ใช้รหัสเดียวกับเว็บหลัก
- `SESSION_SECRET`: ใช้ค่าแบบสุ่มอย่างน้อย 32 ตัวอักษร; ไม่ต้องเหมือน ADMIN_PASSWORD
- ห้ามใส่รหัสทั้งสองใน HTML หรือ GitHub
- ถ้ามีโดเมน Pages แบบ preview เพิ่มเติม ต้องระบุ Origin ที่อนุญาตใน `ALLOWED_ORIGIN` โดยคั่นด้วยคอมมา

ลองเปิด Worker URL + `/health` จะเห็น `{ "ok": true, ... }`

## 3) ผูก GitHub กับ Cloudflare Pages

แก้ `web/config.js` ให้เป็น URL Worker ที่ deploy สำเร็จ เช่น

```js
window.PAYMENT_API = 'https://wanderer-payment-api.YOUR-SUBDOMAIN.workers.dev';
```

สร้าง **GitHub repository ใหม่** และ push โฟลเดอร์ทั้งชุดขึ้นไป

Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git

- Framework preset: None
- Build command: เว้นว่าง
- Build output directory: `web`
- Deploy (Pages จะเผยแพร่เฉพาะไฟล์ใน `web`)

**สำคัญ:** หาก Page URL ที่ได้ต่างจาก `ALLOWED_ORIGIN` ให้แก้ `wrangler.toml` แล้ว `npx wrangler deploy` ใหม่

## 4) ใช้งาน

เปิด URL Pages → ปุ่ม ⚙ แอดมินในกรอบลอย → ใส่ `ADMIN_PASSWORD` → แก้ข้อมูล → บันทึก

- QR และโลโก้: อัปโหลดรูป PNG/JPG/WebP แต่ละรูปไม่เกิน 500 KB
- พื้นหลัง: อัปโหลดภาพและเลือก `พื้นหลังแบบ: รูปที่แนบ`
- รูปลอย: อัปโหลดภาพในหัวข้อรูปตกแต่งลอย และเปิดสวิตช์ `แสดงรูปตกแต่งลอย`
- ข้อความลอย: ตั้งข้อความ ตำแหน่ง X/Y ขนาด และแอนิเมชัน
- ตั้งปุ่ม “เว็บสินค้า” ให้เป็น URL เว็บ Wanderer_Shop หลัก (เป็นลิงก์ออกเท่านั้น)
- หน้าเว็บลูกค้าดึงข้อมูลกลางเมื่อเปิดหน้า/กลับมาแท็บ และตรวจใหม่ทุก 60 วินาที หากมีการแก้ไข

## ข้อควรรู้ก่อนเปิดรับเงินจริง

1. ภาพและเลขบัญชีตั้งต้นเป็นข้อมูลตัวอย่างเท่านั้น ต้องเปลี่ยนทั้งหมดก่อนเปิดใช้งาน
2. ภาพเก็บใน D1 เป็น base64 เพื่อไม่ต้องเปิด R2 ในเวอร์ชันข้อมูลน้อย มี overhead และข้อจำกัดขนาด 500 KB/ภาพ หากรูปมาก/เข้าชมมากให้ย้ายไป R2
3. หน้าแอดมินมีรหัสผ่าน แต่โทเค็นอยู่ใน sessionStorage และมีอายุ 4 ชั่วโมง อย่าใช้เครื่องสาธารณะ และไม่แชร์รหัส
4. ตั้ง `ALLOWED_ORIGIN` ให้ตรงโดเมนหน้าร้านจริง; Origin/CORS ช่วยจำกัดเบราว์เซอร์ แต่ไม่ใช่การยืนยันตัวตน (การแก้ข้อมูลต้องใช้โทเค็น)
5. รักษารหัสลับไว้ใน Cloudflare Secrets อย่าใส่ในไฟล์ GitHub
6. ระบบนี้แยกฐานข้อมูลกับ Worker ของเว็บหลัก ไม่เชื่อมร้านหลักแม้แต่ส่วนเดียว
7. ก่อนใช้จริง ควรทดสอบการเปลี่ยนเลขบัญชี/QR จากแอดมินและตรวจหน้าเว็บบนมือถืออีกเครื่อง
8. ไม่มีระบบสำรองข้อมูลอัตโนมัติ หากใช้รับเงินจริง ควรสำรองข้อมูล D1 และรูปต้นฉบับเก็บไว้ด้วย

## เพิ่มช่อง TrueMoney Wallet
หน้าเว็บลูกค้าแสดงเบอร์วอลเล็ตพร้อมปุ่มคัดลอกแยกจากบัญชีธนาคาร; หน้าแอดมินมีช่อง **เบอร์ TrueMoney Wallet** ให้แก้และบันทึกผ่าน API ลงฐาน D1 กลาง เมื่อโหลดข้อมูลใหม่ทุกเครื่องจะแสดงค่าตรงกัน ถ้าเว้นว่าง หน้าเว็บขึ้นว่า “ยังไม่ได้ตั้งค่า” และปุ่มคัดลอกกดไม่ได้

โปรเจกต์ที่เคยติดตั้ง D1 แล้ว **ไม่ต้องรัน Migration ใหม่** เพราะฟิลด์ `walletNumber` อยู่ใน JSON ของตาราง `site_config` เดิม ให้ deploy Worker และอัปโหลดไฟล์เว็บเวอร์ชันใหม่ทั้งหมดเพื่อให้ตรงกัน


## อัปเดต: ปุ่มคัดลอกโน้ต + พร้อมเพย์ + โลโก้ปรับขนาด

- หน้าเว็บลูกค้ามีกรอบ **พร้อมเพย์ (PromptPay)** และปุ่ม **คัดลอกหมายเลขพร้อมเพย์** (หากไม่ใส่หมายเลขปุ่มจะปิดใช้งาน)
- กล่องโน้ตสลิปมีปุ่ม **คัดลอกโน้ตสลิป** โดยคัดลอกเฉพาะข้อความโน้ตที่ตั้งในแอดมิน
- แอดมิน > ข้อมูลร้านและบัญชี: กรอก **หมายเลขพร้อมเพย์** ได้
- แอดมิน > สีและพื้นหลัง: ปรับ **ขนาดโลโก้** ได้ตั้งแต่ 70–240 px ค่าเริ่มต้น 150 px (บนมือถือมีการย่อขนาดตามความกว้างอุปกรณ์เพื่อไม่ให้ล้น)
- ข้อมูลใหม่เก็บใน JSON config ของ D1 เดิม **ไม่ต้องรัน Migration ใหม่ และไม่ต้องลบฐานข้อมูล**
- อัปเดต Worker จากโฟลเดอร์ `worker/` ด้วย `npx.cmd wrangler deploy` หลังอัปโหลดไฟล์เว็บใหม่ และตรวจสอบ `ALLOWED_ORIGIN` ให้ตรงกับโดเมน Pages จริงโดยไม่ใส่ `/` ท้าย
- สำหรับ GitHub Repo ของคุณที่เก็บไฟล์เว็บไว้ **ระดับบนสุด** ให้คัดลอก **ไฟล์ทั้งหมดใน `web/`** ไปทับไฟล์ระดับบนสุดของ Repo (รวม `config.js`), ไม่ต้องอัปโหลดโฟลเดอร์ `web` ครอบซ้ำ
- ห้ามนำ `ADMIN_PASSWORD` หรือ `SESSION_SECRET` ไปไว้ใน GitHub; ของเดิมยังใช้ได้
